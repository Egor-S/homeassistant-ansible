=================================
egors.homeassistant Release Notes
=================================

.. contents:: Topics

v0.1.0
======

Release Summary
---------------

Initial MVP release of the egors.homeassistant collection.

New Modules
-----------

- egors.homeassistant.analytics - Manage what Home Assistant shares with its analytics.
- egors.homeassistant.area - Manage areas in the Home Assistant area registry.
- egors.homeassistant.area_info - List areas of the Home Assistant area registry.
- egors.homeassistant.area_order - Set the order of Home Assistant areas.
- egors.homeassistant.automation - Manage Home Assistant automations created in the UI.
- egors.homeassistant.backup_config - Manage the automatic backup settings of Home Assistant.
- egors.homeassistant.category - Manage Home Assistant categories.
- egors.homeassistant.category_info - List Home Assistant categories of one scope.
- egors.homeassistant.config_entry - Add and remove Home Assistant integrations (config entries).
- egors.homeassistant.config_entry_info - List Home Assistant config entries.
- egors.homeassistant.config_entry_options - Set the options of a Home Assistant config entry.
- egors.homeassistant.core_config - Manage the Home Assistant core configuration.
- egors.homeassistant.counter - Manage Home Assistant counter helpers.
- egors.homeassistant.dashboard - Manage Home Assistant dashboards and their content.
- egors.homeassistant.dashboard_resource - Manage Home Assistant dashboard resources.
- egors.homeassistant.device - Manage the settings of a Home Assistant device.
- egors.homeassistant.device_info - List devices of the Home Assistant device registry.
- egors.homeassistant.energy_prefs - Configure the Home Assistant energy dashboard.
- egors.homeassistant.entity - Manage the settings of a Home Assistant entity.
- egors.homeassistant.entity_info - List entities of the Home Assistant entity registry.
- egors.homeassistant.expose_new_entities - Choose whether new entities are exposed to voice assistants.
- egors.homeassistant.exposed_entity - Expose Home Assistant entities to voice assistants.
- egors.homeassistant.floor - Manage floors in the Home Assistant floor registry.
- egors.homeassistant.floor_info - List floors of the Home Assistant floor registry.
- egors.homeassistant.floor_order - Set the order of Home Assistant floors.
- egors.homeassistant.helper_info - List Home Assistant helpers of one type.
- egors.homeassistant.http_config - Manage the Home Assistant HTTP server configuration.
- egors.homeassistant.input_boolean - Manage Home Assistant toggle (input\_boolean) helpers.
- egors.homeassistant.input_button - Manage Home Assistant button (input\_button) helpers.
- egors.homeassistant.input_datetime - Manage Home Assistant date and/or time (input\_datetime) helpers.
- egors.homeassistant.input_number - Manage Home Assistant number (input\_number) helpers.
- egors.homeassistant.input_select - Manage Home Assistant dropdown (input\_select) helpers.
- egors.homeassistant.input_text - Manage Home Assistant text (input\_text) helpers.
- egors.homeassistant.label - Manage labels in the Home Assistant label registry.
- egors.homeassistant.label_info - List labels of the Home Assistant label registry.
- egors.homeassistant.logger_level - Set the log level of a Home Assistant integration.
- egors.homeassistant.login - Log in to Home Assistant and get a short\-lived token for the other modules.
- egors.homeassistant.network - Choose the network adapters Home Assistant uses.
- egors.homeassistant.onboarding - Onboard a fresh Home Assistant instance.
- egors.homeassistant.person - Manage Home Assistant people.
- egors.homeassistant.person_info - List Home Assistant people.
- egors.homeassistant.scene - Manage Home Assistant scenes created in the UI.
- egors.homeassistant.schedule - Manage Home Assistant weekly schedule helpers.
- egors.homeassistant.script - Manage Home Assistant scripts created in the UI.
- egors.homeassistant.tag - Manage Home Assistant tags (NFC tags and QR codes).
- egors.homeassistant.tag_info - List Home Assistant tags.
- egors.homeassistant.timer - Manage Home Assistant timer helpers.
- egors.homeassistant.user - Manage Home Assistant users.
- egors.homeassistant.user_info - List Home Assistant users.
- egors.homeassistant.zone - Manage Home Assistant zones.
- egors.homeassistant.zone_info - List Home Assistant zones.
